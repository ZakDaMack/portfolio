    - title: "Kubernetes, even for one"
      description: "Containerised in Docker and run highly available on Kubernetes. It ships and recovers like a team product."
  outcome: "A live site that always knows the cheapest fuel nearby, refreshed every 15 minutes, with a mobile-first React frontend and powered by Go. Every layer, built and run by one person."
